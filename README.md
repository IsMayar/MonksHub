# MonksHub Frontend

MonksHub is a polished frontend for a mentor-led online learning platform. It
showcases real course catalog content, mentor profiles, insights, a contact
flow, responsive navigation, and animated page transitions.

## Stack

- React and Vite
- TypeScript content and route layer
- Tailwind CSS
- Local shadcn-style UI primitives
- Framer Motion animations
- React Router

## Scripts

```bash
npm install
npm run dev
npm run build
```
